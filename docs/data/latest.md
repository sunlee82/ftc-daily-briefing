# [공정위동향] 2026.11.10.(화)

## 배민·쿠팡 최혜대우 요구에 역대 최대 과징금 6,319억

### 오늘의 핵심

- **배민 3,311억·쿠팡 3,008억** 과징금 — 최혜대우 요구·자체배달 전환 강제, 사실상 **담합 효과** 판단
- 쿠팡 **끼워팔기** 사건은 심사보고서 해석 이견으로 **재심사 명령** — 양사 "위법성 없다·형평성 어긋나" 반발
- 기업결합 **이행감독기구** 구성·운영 고시 개정안 행정예고 — 의견제출 **12월 1일**까지

### 공정위 보도자료 (2건)

**배달앱 불공정행위 제재**

배민·쿠팡의 최혜대우 요구 등 시장지배적지위 남용에 시정명령·과징금 **6,319억원** 부과
- 배민 **3,311억**(최혜대우 1,602억·자체배달 전환 강제 1,554억·배달예상시간 기만광고 154억), 쿠팡 **3,008억**(모두 잠정) — **10월 29일** 전원회의 결정
- 쿠팡은 **'23.7~'26.1** 와우매장, 배민은 **'24.5~'25.10** 배민클럽가게 지위를 지렛대로 메뉴가격·최소주문금액 등을 경쟁앱과 같거나 유리하게 설정하도록 요구 — 합산 점유율 **90%** 넘는 두 사업자의 동시 MFN으로 담합과 유사한 경쟁제한 효과 판단
- 배민은 가게배달(MP) 노출 축소·가게통합·울트라콜 폐지로 자체배달(OD) 전환을 사실상 강제('25.3.부터 강제성 인정), 수수료율 **6.8%→9.8%** 인상 — MP 배달예상시간을 실제보다 약 **13분** 느리게 보이도록 광고한 행위는 기만광고
- 쿠팡의 '할인 전 판매가' 기준 중개·결제수수료 약관 조항은 약관법 위반 시정명령(**60일 내** 수정), 쿠팡 끼워팔기(거래강제) 건은 주된·종된 상품 개념 해석 이견으로 **재심사 명령**

**기업결합 시정조치 부과기준 고시 개정안 행정예고**

기업결합 시정조치 이행감독기구 구성·운영 근거를 담은 고시 개정안 **12월 1일**까지 행정예고
- 결합당사회사와 독립된 자를 **공정위 승인**을 받아 이행감독위원회 위원으로 선임, 독립·공정한 직무수행이 어려우면 공정위가 해임 요구
- 위원 보수는 산정기준·금액까지 공정위 승인, 승인된 보수 외 경제적 이익 제공 금지
- 이감위는 공정위 지도·감독 아래 점검 결과를 **정기 보고**, 결합당사회사에 자료 제출 요구·사업장 방문 점검 권한 — 보고가 불충분하면 해산·재설치 또는 공정위 직접 점검
- 독임제 이행감독인도 감독기구로 규정(이감위 규정 준용), 시행 이후 **신고서 접수 사건부터** 적용 — 의견제출 **12월 1일**까지, 전원회의 의결 거쳐 시행
