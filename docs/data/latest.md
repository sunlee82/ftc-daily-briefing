# [공정위동향] 2026.11.18.(수)

## 쿠팡·김범석 지정자료 허위제출 고발 여부 심의 착수

### 오늘의 핵심

- 공정위 사무처, **쿠팡·김범석 의장** 총수 지정자료 허위 제출에 **고발 의견** — 전원회의 심의 착수
- 방문판매법 시행령 국무회의 통과 — 위반 가담 임직원도 신고포상금, **1천만원 한도 폐지**해 과징금 **최대 10%**
- **LG유플러스** 5G 속도 과장광고 과징금 소송 **패소 확정** — SKT **168억** 사건은 대법원 상고심 진행 중

### 공정위 보도자료 (2건)

**방문판매법 시행령 개정안 국무회의 통과**

방판법 위반 신고포상금을 가담 임직원까지 확대하고 **1천만원** 한도를 폐지하는 시행령 개정안 국무회의 의결
- 법 위반에 가담한 임직원도 포상금 지급 대상에 포함 — 가담 정도에 따라 지급액 감액 가능
- 포상금 한도 **1천만원** 삭제 → 과징금 부과액의 **최대 10%**까지 지급(**6월 18일** 개정 포상금 규정과 연동)
- **공포 즉시 시행**, 공포 전 신고분은 종전 규정 적용. 시행령 제51조 제4항 '1천만원 한도' 문구 삭제

**보습크림 8종 품질 비교정보 제공**

한국소비자원, 보습크림 **8종** 보습력·사용감·안전성·가격 비교 결과 공개
- 보습력은 라로슈포제·에스트라·이니스프리 **3개**, 수분 증발 감소도는 세타필·에스트라·이니스프리·일리윤·피지오겔 **5개**가 상대적 우수. 표피 이하 수분 증가도는 전 제품 양호
- 중금속 **7종**·보존제 **6종** 안전성, 내용량·의무표시사항 전 제품 적합. 재활용 용이성 '우수' **4개**·'보통' **4개**
- 단위(mL·g)당 가격 **66~456원**, 최대 **6.9배** 차 — 세타필 최저·라로슈포제 최고. 사용 만족도는 세타필 **4.0점** 최고
- 결과는 '소비자24' 비교공감 코너에 게재 예정
