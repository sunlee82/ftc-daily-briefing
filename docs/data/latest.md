# [공정위동향] 2026.11.23.(월)

## OK금융 일감 몰아주기·사익편취 의혹, 최윤 회장 고발 의견

- **OK금융** 일감 몰아주기·총수 사익편취 의혹 — 공정위 사무처, **최윤 회장 고발 의견**
- 상표권 수익 빼면 적자인 대기업 계열사 **13곳** — 공정위 '**상표권 가이드라인** 마련' 방침

OK금융그룹 계열사 간 일감 몰아주기와 총수 사익편취 의혹이 대상(경향신문 단독).

**상표권 수익 빼면 사실상 적자인 대기업 계열사 13곳…공정위 "상표권 가이드라인 마련"**

계열사에서 받는 상표권 수익이 순이익보다 많아 이를 빼면 사실상 적자인 대기업 계열사 **13곳** 집계(2025년 실적).
공정위는 상표권 사용료 가이드라인을 마련하겠다는 입장 — **11월 19일** 내부거래 현황에서 **SK·LG**가 연 **2,000억** 이상 수취 집단으로 공개된 뒤 나온 후속.

출처: https://www.chosun.com/economy/economy_general/2026/11/23/CMO6X6OF6NDFHIVKC2QQW5NRWU/

**대리점 분야 공정거래협약 이행평가, 매일유업·남양유업 '최우수'…6곳 양호 이상**

최우수 등급 2개사는 **2년간** 공정위 직권조사 면제(헤럴드경제·MTN 등 10여 매체 공통).

출처: https://www.ddaily.co.kr/page/view/2026112217182651236
