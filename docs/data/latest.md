# [공정위동향] 2026.10.20.(화)

## GIS 입찰담합 391억 과징금 소송, 공정위 잇따라 승소

### 오늘의 핵심

- 전력기기 업체 **GIS 입찰담합** 과징금 **391억원** 취소소송, 법원이 공정위 처분 잇따라 인정
- '10대 로펌 퇴직자 **124명**' 보도에 공정위 "취업심사·외부인 접촉보고로 유착 차단" 반박
- 상조·유통 법 개정, 전분당 담합 적발 등 직원 **28명**에 특별성과 포상금 **3,400만 원**

### 공정위 보도자료 (2건)

**공정위, 제3회 특별성과 포상금 수여**

상조·유통 법 개정과 전분당 담합 적발 등 8개 과제 직원 28명에 특별성과 포상금 수여
- **10월 7일** 수여식, 총 **3,400만 원** — 할부거래법·대규모유통업법 개정 **700만 원** 최다
- 전분·전분당 담합 적발, 대한항공-아시아나 마일리지 통합안 각 **500만 원**
- 을의 협상력 강화·제주 주유소 제재 각 **400만 원**, 명륜당 제재·쿠팡 동일인 변경·쉰들러 ISDS 승소 각 **300만 원**
- 상조업체 지배주주 대여금 제한·공정위-금감원 합동조사반 근거, 유통 대금지급기한 단축이 포상 사유

**[설명] 서울신문(10.19.) 10대 로펌에 공정위 퇴직자만 124명...등 기사 관련**

'10대 로펌 공정위 퇴직자 124명' 보도에 퇴직자 영향력 행사·비상임위원 이해충돌 부인
- **7급 이상** 직원은 퇴직 후 **3년간** 업무관련 로펌 취업 제한(타 부처는 4급 이상)
- 로펌·대기업·퇴직자 접촉은 공무상 접촉까지 전부 보고, **올해 3월** 규정 개정으로 **2회 이상** 반복 위반 시 원칙 징계
- 비상임위원 A·B는 철도침목·맨홀뚜껑 담합 사건 심결에 참여하지 않았거나 제척돼 이해충돌 아님
- 취업심사·외부인 접촉 관리·위원 제척·회피 제도를 계속 엄정 운영 방침

### 언론 보도 (1건)

**GIS 입찰담합 391억 과징금 줄소송, 공정위 잇따라 승소**

가스절연개폐장치(GIS) 구매 입찰 담합으로 전력기기 업체들에 부과된 **391억원대** 과징금이 대상.
