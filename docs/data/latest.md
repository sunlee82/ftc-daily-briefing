# [공정위동향] 2026.11.6.(금)

## 화물연대 공정위 조사 거부, 2심서 유죄로 뒤집혀…벌금 3천만원

### 오늘의 핵심

- **화물연대** 2022년 총파업 당시 공정위 현장조사 거부, 1심 무죄 → 2심 **유죄·벌금 3,000만원**
- 결혼서비스 **568곳** 중 가격 공개 **53%** — 미표시 **17곳** 과태료 **1,560만원** 확정, **11월 2일** 전담 신고센터 운영
- **쿠팡** 10년치 자료제출명령 효력정지 심문 — "본보기성 조사" vs 공정위 "별개 조사·제출 지연"

### 공정위 보도자료 (1건)

**결혼분야 모니터링 최종결과 및 위반 사업자에 대한 제재**

예식장·결혼준비대행 **568개사** 가격공개 모니터링 결과 발표, 미표시 **17곳**에 과태료 부과
- 예식장 **418곳**·대행업 **150곳** 중 **301곳(53.0%)** 가격 공개 — 1차 **29.2%**에서 **23.8%p** 상승, 참가격 게시 **161→274곳**
- 주요 **50곳** 집중점검서 대행업 11·예식장 6곳이 계약서 표지·누리집에 가격 미표시 — **10월 말** 과태료 총 **1,560만원** 확정(다이렉트컴즈 **240만원** 최다, 에이케이플라자 노보텔수원·소노인터내셔널 포함)
- 정보공개 방법 개선안: 누리집·참가격에 다운로드 가능한 형태로 게시 **필수**, 계약서 표지엔 판매량 상위 **10개** 대표업체 가격 명시 후 별지·전자기기 열람 허용
- **11월 2일**부터 공정위 홈페이지에 결혼분야 중요정보고시 위반 전담 신고센터 운영, 미준수 업체는 내년 모니터링 대상 포함
